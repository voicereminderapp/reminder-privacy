This application does not collect, store, or share any personal information. All reminders and data created by the user are stored locally on the user's device and are not transmitted to any external servers.

The application may request permission to send notifications in order to deliver reminder alerts. These notifications are used solely for the core functionality of the application.

The app does not access:

All reminder data is stored locally on the device. The developer does not have access to this data.

Third-Party Services

This application does not use third-party analytics, advertising networks, or external data collection services.

Children's Privacy

This application does not knowingly collect personal information from children under the age of 13.
